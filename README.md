# Progress Pal

Make a animated progress bar adder. It's functionality is, 
I can name a task and create a progress bar for it on my dashboard, 
I'll have a + and - sign to increase or decrease progess.
It's a customizable progress bar adder that will help me keep track of my progress.
The bar itself should have passive animation going on for the filled up portion, something energizing and at first, it should be red when going up from 0
closer it is it 100, it should start turning green.
At 100% it should look fully green. 
DESIGN:

Inspired from : https://shocheton.vercel.app/ but the background grid needs to be slowly moving to make it feel more dynamic. rest of the design can stay the same, just instead of cyan, you can use bright orange
